# ⚡ 비트 (BEAT) : 비전공자를 위한 코딩테스트
> **비전공자 및 코딩 입문자를 위한 Java 기반 0단계 기초 코딩테스트 & 채점 시스템**

비전공자나 코딩을 처음 접하는 분들도 부담 없이 시작할 수 있도록 **0단계 기초 문제(문자열 출력, 사칙연산, 조건문, 비교 연산자, 백분율 계산)**부터 시작하여, **채점관에게 제출해 점수를 쌓고(총 100점 만점) 비트 마스터 인증을 받는 인터랙티브 코딩테스트 플랫폼**입니다.

---

## 🏆 비트 Lv.0 코딩테스트 단계별 로드맵

| 단계 | 문제명 | 핵심 학습 내용 | 담당 채점관 | 배점 |
| :---: | :--- | :--- | :---: | :---: |
| **1단계** | 비트 시작 인사 출력하기 | 문자열 반환 기초 (`return "Hello Beat!";`) | 👨‍💻 김민우 멘토 | **+20점** |
| **2단계** | 두 수의 합 구하기 | 변수와 덧셈 연산자 (`return a + b;`) | 📋 이지은 출제위원 | **+20점** |
| **3단계** | 짝수와 홀수 판별하기 | 조건문과 나머지 연산 (`if (num % 2 == 0)`) | 👨‍💻 김민우 멘토 | **+20점** |
| **4단계** | 성인 인증 조건 판별하기 | 비교 연산자와 참/거짓 (`return age >= 19;`) | 📋 이지은 출제위원 | **+20점** |
| **5단계** | 10% 할인 금액 계산기 | 퍼센트 백분율 수식 (`price * 90 / 100`) | 👩‍💼 박수현 수석 평가위원장 | **+20점** |

* 🎖️ **비트 등급 변화:** 0점(비트 입문자) ➔ 20~40점(초급 도전자) ➔ 60~80점(중급 도전자) ➔ **100점 만점 달성 시 "🎉 비트 마스터 (Lv.1 합격)"**

## 🛠️ 주요 기능

1. **💻 비트 IDE (웹 자바 에디터):**
   * 브라우저 내에서 직접 자바 코드를 편집하고 실행할 수 있는 Web IDE
   * **🎯 [답 작성 위치 안내 배너]:** 어디에 답을 적어야 할지 한 줄 한 줄 한국어로 친절히 안내
   * **⚡ [간편 정답 입력기]:** 복잡한 자바 코드를 헤매지 않고 답만 적고 [채우기]를 누르면 코드에 자동 반영
   * **`[▶ 단위 테스트 실행]`:** 내가 작성한 코드가 정답인지 즉시 검증
   * **`[📋 채점관에게 제출 & 점수 받기]`:** 채점관 결재 도장 및 피드백 리포트와 함께 상단 점수 게이지 실시간 적립
   * **`[💡 멘토 힌트]`:** 막힐 때 정답 코드 확인 및 에디터 자동 채우기 지원

2. **💬 튜터 챗 (1:1 멘토링):**
   * 김민우 멘토, 이지은 출제위원, 박수현 수석 평가위원장에게 언제든 힌트와 코딩 문법 질문 가능

3. **📋 문제 현황판:**
   * 내 풀이 진행 상황을 한눈에 볼 수 있는 칸반 보드

4. **📖 자바 기초 치트키 위키:**
   * 비전공자를 위한 핵심 자바 문법 가이드
