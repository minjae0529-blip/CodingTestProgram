📖 비전공자를 위한 비트(BEAT) 자바 기초 핵심 정리

코딩테스트를 처음 접할 때 꼭 알아두어야 하는 3가지 필수 문법입니다!

1. return (결과값 돌려주기)

메서드는 답을 구할 때 return 키워드로 반환합니다.

// 글자를 돌려줄 때는 큰따옴표("")로 감쌉니다.
return "Hello Beat!";

// 숫자를 돌려줄 때는 숫자 그대로 씁니다.
return 100;

2. 사칙연산과 나머지

더하기(+), 빼기(-), 곱하기(*), 나누기(/), 그리고 나머지(%) 연산자를 사용합니다.

int a = 10;
int b = 20;
return a + b; // 30이 반환됨

3. 조건문 (if - else)

조건에 따라 다른 답을 낼 때 사용합니다.

// 짝수인지 판별하기
if (num % 2 == 0) {
    return "Even"; // 2로 나눈 나머지가 0이면 짝수
} else {
    return "Odd";  // 그렇지 않으면 홀수
}
